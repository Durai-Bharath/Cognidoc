# Stage 1 traceability: algorithm → class → file → tests

Each of the 21 algorithms in *Agentic Document Extraction Framework* maps to exactly one
class. `tests/extraction/test_traceability.py` parses the table below and fails if any row
names a class, file or test that does not exist, so this matrix cannot silently drift.

## Validation checks per algorithm

Every "Validate …" block in the PDF is implemented as named `CheckResult`s (pass/fail with
reasons). *Warning* checks are reported but never fail an outcome (see DESIGN_DECISIONS.md #8).

| Alg | Checks (error unless marked *warning*) |
|---|---|
| 6 | `no_overlapping_regions`, `valid_reading_regions`, `caption_alignment`, `table_alignment`, `figure_alignment` |
| 7 | `no_duplicated_elements`, `no_missing_elements`, `correct_column_transitions`, `valid_caption_associations`, `preserve_document_hierarchy` |
| 8 | `section_continuity`, `non_empty_sections` (*warning*), `hierarchy_consistency`, `object_association`, `no_orphan_content` |
| 9 | `no_missing_chunks`, `correct_chunk_sequence`, `valid_semantic_links`, `consistent_metadata` |
| 10 | `header_consistency`, `missing_cells`, `caption_association` (*warning*), `structural_integrity` |
| 11 | `caption_association` (*warning*), `legend_consistency`, `object_completeness`, `workflow_integrity` |
| 12 | `syntax_correctness`, `variable_consistency`, `equation_reference_mapping`, `latex_integrity` |
| 13 | `broken_references`, `duplicate_citations`, `invalid_numbering`, `missing_target_objects` |
| 14 | `broken_references`, `object_uniqueness`, `duplicate_references` (*warning*), `invalid_numbering`, `reference_targets`, `orphan_objects` (*warning*), `circular_references` (*warning*) |
| 15 | `duplicate_entities`, `missing_descriptions`, `invalid_classifications`, `context_consistency` |
| 16 | `duplicate_abbreviations` (*warning*), `conflicting_definitions`, `undefined_abbreviations` (*warning*), `unused_abbreviations` (*warning*) |
| 17 | `summary_completeness`, `context_preservation`, `factual_consistency`, `length_constraints` |
| 19 | `missing_scores`, `invalid_values`, `score_consistency` |
| 20 | `metadata_schema`, `json_schema` |
| 21 | `document_information`, `section_hierarchy`, `page_numbering`, `document_statistics`, `tables`, `figures`, `equations`, `entities`, `abbreviations`, `cross_references`, `section_summaries`, `keywords` (*warning*), `confidence_scores`, `object_associations`, `required_fields`, `object_hierarchy`, `data_types`, `duplicate_entries`, `broken_references`, `missing_objects`, `orphan_sections` (*warning*), `invalid_relationships` |

Alg. 2–5 and 18 have threshold or branch decisions rather than "Validate" blocks: accessibility
and type routing (2), τ (3), τ_quality (4), ΔC > 0 (5) and HScore ≤ τ (18). Those branches are
covered by the tests listed above.
